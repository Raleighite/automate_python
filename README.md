# Automate the Boring Stuff with Python — Exercises

Practice exercises from *Automate the Boring Stuff with Python* by Al Sweigart (chapters 1–8).

## Contents

Each `.py` file corresponds to a chapter exercise or practice project:

- `collatz.py` — Collatz sequence
- `guess.py` — Guess the number game
- `inventory.py` — Fantasy game inventory
- `ticTacToe.py` — Tic-tac-toe board display
- `tablePrinter.py` — Pretty-print tabular data
- `pw.py` — Password manager (practice)
- And more...

## Running

```bash
python3 <filename>.py
```

Requires Python 3.x. No external dependencies.
